# russian-teacher

A single-page Russian tutor for Hebrew speakers, served with GitHub Pages at
https://selamalka.github.io/russian-teacher/

## Files

- `index.html` is the whole app: lessons, dictionary and lookup.
- `stress.txt` maps about 205,000 Russian word forms to the position of their
  stressed vowel. The app loads it on demand to add stress marks to
  machine-translated sentences.

## Data credits

`stress.txt` is derived from the OpenRussian dictionary data
(https://github.com/Badestrand/russian-dictionary, https://en.openrussian.org),
licensed under Creative Commons Attribution-ShareAlike 4.0. The derived file is
shared under the same licence.

Free-text translation uses the MyMemory translation API
(https://mymemory.translated.net).
